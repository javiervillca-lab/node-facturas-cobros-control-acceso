# Control de acceso - domain

Este directorio representa la capa de domain del contexto de control de acceso.

## Objetivo

Definir entidades, agregados y políticas relacionadas con usuarios, permisos y accesos.

## Recomendación

- Mantener la lógica de negocio del acceso en esta capa.
- Evitar dependencias de infraestructura o APIs externas.
